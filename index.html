Cross-Platform Support

Multi-Database Support

Web-Based GUI (Windows)

Beautiful Flask-based web interface for Windows edition. Intuitive UI for easy configuration and monitoring of sync operations.

💻

CLI Interface (Linux)

Clean and readable CLI logs for Linux/macOS. Perfect for automation scripts and terminal-based workflows.

Modular Architecture

Handles encoding and logging with precision. Automated logging with status tracking ensures data integrity throughout the sync process.

Simple Launchers

Easy-to-use launchers: xcelsync.sh for Linux/macOS (CLI) and xcelsync.bat for Windows (Web-based GUI).

Easy Setup

Installation

Get started in minutes with platform-specific instructions

🪟 Windows

Windows Installation

1

Download Cross-Platform Version

Download the XcelSync-CrossPlatform.zip from releases.

2

Run the Launcher

Double-click xcelsync.bat. It will automatically detect if Python is installed and guide you through the setup.

3

Python Installation (if needed)

If Python is not detected, install Python 3.3+ from python.org. The launcher will handle dependencies automatically.

4

Launch Web GUI

Run xcelsync.bat or web_app.py to start the web-based GUI. Open your browser to the displayed URL.

🐧 Linux

Linux Installation

1

Clone the Repository

git clone https://github.com/ad1xmohd/XcelSync.git
cd XcelSync
2

Install Python Dependencies

pip install -r requirements.txt --break-system-packages

💡 Optional: Use a virtual environment for isolated installs:

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
3

Make Script Executable

chmod +x xcelsync.sh
4

Run the Main Script

./xcelsync.sh

The script orchestrates Python modules: main.py (controller), importer.py (Excel processing), and logger.py (logging).

🚀 XcelSync

XcelSync is an intelligent data synchronization and automation tool for Excel and CSV workflows. It streamlines file updates, merging, and cross-sheet syncing for managing datasets efficiently.

Features

  • ✅ Import Excel/CSV to MySQL, PostgreSQL, SQLite
  • ⚙️ Intelligent file merging and synchronization
  • 🧩 Automated logging and UTF-8 safe handling
  • 📊 Ideal for data automation and ETL workflows
